# audio-suite

Acoustic analysis CLI for objective defect detection and perceptual quality assessment.

## Principle

> **The audio-suite does not transform subjective descriptors into automatic failures.**
> - Descriptive metrics (centroid, BPM, key) → **observation / baseline / needs_review**
> - Objective defects (clipping, glitch, mono cancellation) → **warning / fail via profile**
> - Semantic inferences (emotion, authorship) → **needs_review** with documented limitation

## Installation

```bash
pip install -e ".[dev]"
python scripts/gen_fixtures.py  # generate test fixtures
```

## Usage

```bash
# Quick metadata
audio-suite inspect path/to/audio.wav

# Validate a profile
audio-suite validate profiles/strict.yaml --strict

# Run analysis
audio-suite analyze path/to/audio.wav --format json
audio-suite analyze path/to/audio.wav --format sarif --output results.sarif
audio-suite analyze path/to/audio.wav --format html --output report.html

# Strict mode + signed bundle
audio-suite analyze path/to/audio.wav --strict --sign --signing-key key.pem
```

## Exit codes

| Code | Meaning |
|------|---------|
| 0 | OK — analysis ran, no fail-level findings |
| 1 | FINDING — analysis ran, at least one fail-level finding |
| 2 | INVALID_PROFILE — profile YAML failed validation |
| 3 | INVALID_INPUT — input audio could not be decoded / missing |
| 64 | USAGE — CLI usage error |

## Analyzers (v0.1)

| ID | Phase | What it does |
|----|-------|--------------|
| inspect | 1 | Technical metadata extraction |
| loudness | 1 | ITU-R BS.1770-4 integrated loudness (LUFS) |
| true_peak | 1 | True peak (dBTP) with 4x oversampling |
| clipping | 1 | Hard clipping detection |
| glitch | 1 | Click / dropout / repetition detection |
| mono_compat | 1 | Per-band phase cancellation loss |
| channel_balance | 1 | L/R LUFS+RMS imbalance |
| loop | 1 | Loop-point continuity (opt-in) |
| spectral_health | 2 | Centroid / flatness / rolloff (descriptor) |
| lra | 2 | Loudness Range (EBU R128) |
| codec_conf | 2 | Codec metadata conformance |
| resampling | 2 | Aliasing & bandwidth artifacts |
| transient | 2 | Attack-time smearing |
| voice_artifacts | 2 | Plosives / sibilance (objective) |
| ref_quality | 2 | STOI/ViSQOL/SI-SDR proxies + no-ref indeterminate |
